01 · Transform

Move it like you mean it.

Press G, R or S and drag. A live chip reads distance or degrees as you go, and axis guide lines keep you honest. Or type it in the numeric inspector: position, lift, rotation, size.

0.60 s to open a 92 MB, 1.9-million-triangle miniature

02 · Hollow

Save resin without guessing.

A translucent cavity preview that follows the wall slider live, a Recommended thickness one click away, fine ±0.1 and ±1 mm steps, and drain holes before or after.

0.81 s for the live cavity. Meanwhile the supports are being made in the background.

03 · Supports

Hold it up, by hand or in one click.

Trunks, branches, leaves, braces and rafts, prepared in the background while you worked, so Generate is often instant. Add with A, remove with X, with a live preview before every click.

0.17 s from Generate to 124 supports on screen: they were ready before the click

04 · Slice

Read every layer before the printer does.

Print time, resin and weight. Then a split view that zooms to 32× with crisp, honest pixels. Sealed cavities slice correctly: what you see is what gets exposed.

0.79 s to slice 913 layers

05 · Export

Write the file. Go print.

The file your printer reads, with a progress readout you can trust. The app stays responsive while it writes, and your project keeps its state, so a last-minute fix is one tab away.

13.8 s to write the 23.9 MB printer file

Check it yourself

Same model, your machine.

Download the wolverine exactly as it was posed for this run and time it on your own computer. Turn on Diagnostic log in Preferences and Breadslicer writes every step to session.log, so the numbers are there to read, not to trust. It is off by default: nothing is logged unless you ask.

03 / Built native Rust · Slint · wgpu

No browser underneath.

Breadslicer is a Rust application with a Slint interface and its own wgpu viewport. Not a web app wearing a window. It shows at startup, on disk, and in how the viewport feels under your hand.

RustLanguage, end to end. Memory-safe geometry, no garbage collector in the loop.
Slint + wgpuNative UI toolkit and a purpose-built GPU viewport. No Electron, no WebView.
~48 MBOne executable. Light on disk, quick to start.
Background jobsSupports and hollowing run off the UI thread. Cancel, undo and stale-result handling are part of the design.
Measured, not guessedEvery engine change is checked against reference scenes, byte for byte, before it ships.
AGPL-3.0Free software. The source opens with the first public build.
04 / Roadmap No dates, no promises we can't slice

What's in the oven.

  1. Coming

    A walk-through that gets exposure right for a new resin without a spreadsheet.

    Structural support checks

    Force-based analysis that flags supports likely to fail before the print does.

  3. Coming

    Split pre-supported STLs into bodies

    Pull a pre-supported file apart into model and supports so each can be edited on its own.

  4. Coming

    Community bug reporting via Discord

    Report from inside the app, with the context attached, straight to the people who fix it.
