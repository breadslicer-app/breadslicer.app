While you work, unsaved changes are kept in the background, never in the middle of a drag. If Breadslicer closes without saving, the next start offers each scene back, in its own window, pointing at its original file.

Saving over a project keeps the previous version first, so *File › Previous Versions…* can open any of the last ten.
