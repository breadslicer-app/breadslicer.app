The file your printer reads, encoded on every core, from **Export** in the Slice tab. Each format we write is checked by reading the file back with UVtools, an open-source resin file tool, and comparing every layer pixel by pixel. See the [supported printers and formats](/printers/).

ELEGOO printers on your network can receive it straight away: **Send**, or **Send and start**, with the printer's camera a click away.
