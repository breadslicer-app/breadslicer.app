Breadslicer 0.5.0-beta.2 is out, a day after [the first open beta](/blog/v0.5.0-beta.1-release/). Get the [installer](https://github.com/breadslicer-app/breadslicer/releases/download/v0.5.0-beta.2/Breadslicer-0.5.0-beta.2-windows-x64-setup.exe) (42.5 MB), which installs over 0.5.0-beta.1, or the [portable zip](https://github.com/breadslicer-app/breadslicer/releases/download/v0.5.0-beta.2/Breadslicer-0.5.0-beta.2-windows-x64.zip) (57.1 MB). Both are on the [release page on GitHub](https://github.com/breadslicer-app/breadslicer/releases/tag/v0.5.0-beta.2). This is the last version you have to fetch by hand: from now on, Breadslicer tells you when there is a new one.

## New

- **Updates from the window.** A few seconds after Breadslicer opens, it asks GitHub once whether there is a newer version. When there is, a small button in the top bar offers it. One click downloads the installer and checks it against the size and checksum GitHub publishes; another closes Breadslicer and runs it. It never installs over unsaved work or while something is running. Turn it off in Preferences > Privacy; **Help > Check for Updates** asks by hand.
- **Cutting a pre-supported model.** The pieces you cut off now get Breadslicer's supports of their own, in the same undo step as the cut. The piece the file's supports hold keeps them. See [Cut along a line you draw](/blog/cutting-and-placing/) and [Telling supports from the model in a pre-supported STL](/blog/pre-supported-files/).
- **Breadslicer Dev.** There is now a second channel with the work in progress, published on GitHub as pre-releases: what is new reaches it before a release, rough edges included. It installs as **Breadslicer Dev**, an app of its own beside Breadslicer, with its own folder, Start menu entry and uninstaller. Both share your settings, printers, resins and recent files, and each one only hears of updates on its own channel. The first one, [0.5.0-dev.1](https://github.com/breadslicer-app/breadslicer/releases/tag/v0.5.0-dev.1), has the same code as this beta. For everyday prints, stay on the release.

The printers are the same 171 as in 0.5.0-beta.1, each with [its own page](/printers/).

## Before you print

The printer tested on real prints is the **Anycubic Photon Mono M7 Pro**. On any other printer, check the first print closely: the model in the right place on the plate, text not mirrored, and the right exposure.

The installer is not signed yet, so Windows may say "Windows protected your PC". Click **More info**, then **Run anyway**.

## Reporting problems

**Help > Export Diagnostics...** saves a zip that helps us understand a problem, without your folder paths or user name. Report on the [issues page](https://github.com/breadslicer-app/breadslicer/issues) or on [Discord](/community/), and say whether it was the release or the Dev build.
